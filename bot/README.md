# newwave бот: Telegram + Gmail + Mail.ru (ЖИ-сыз)

ЖИ жоқ, API кілті жоқ, төлем де, жазылым да жоқ. Бот **дайын жауаптармен** жұмыс істейді.

## ⚡ Жылдам бастау (3 қадам)

1. **Python орнатыңыз** (бір рет): https://www.python.org/downloads/
   Windows-та орнатқанда **«Add Python to PATH»** белгісін міндетті түрде қойыңыз.
2. **Ботты іске қосыңыз:**
   - Windows: `start.bat` файлын екі рет басыңыз.
   - Mac / Linux: терминалда `bash start.sh` деп жазыңыз.

   Бірінші рет ашқанда бот керек нәрселерді өзі орнатады, содан кейін **токенді сұрайды**. Токенді Telegram-дағы @BotFather береді: `/newbot` командасын жазыңыз. Gmail мен Mail.ru керек болмаса, Enter баса беріңіз.
3. Экранда **6 таңбалы код** шығады. Telegram-да өз ботыңызға **сол кодты жазыңыз**, сонда бот сізді иесі деп таниды. Болды! ✅

Келесі жолы тек `start.bat` (немесе `start.sh`) файлын ашсаңыз жетеді.
Бот терезе ашық тұрғанда жұмыс істейді. Тәулік бойы жұмыс істеуі үшін 8-бөлімді қараңыз.

## Бот не істейді

**Telegram:**
- Клиентке **мәзір батырмалары** көрінеді: 💰 Бағалар, 📦 Пакеттер, 🎨 Дизайн, 🛠 Кезеңдер, 📞 Байланыс, ✍️ Иесімен сөйлесу.
- Клиент мәтінмен жазса, бот **кілт сөздер** бойынша дайын жауапты табады.
  Мысалы, «қанша тұрады» немесе «сколько стоит» деп жазса, бағаны жібереді. «Дизайн көрсет» немесе «примеры» десе, **дизайн суреттерін** жібереді.
- Бот қазақша немесе орысша жазылғанын өзі анықтап, сол тілде жауап береді.
- **«Іс» болса** («заказать», «тапсырыс», «скидка», «менеджер», «позвоните» т.б.), бот клиентке «иесіне жібердім» дейді, ал сізге 🔥 хабар келеді.
- **Бот түсінбеген сұрақ** болса, сізге ❓ хабар келеді.

**Gmail / Mail.ru:**
- Жаңа хатқа бот бірден **автожауап** жібереді: «хатыңыз қабылданды, иесі жауап береді». Хатта баға, мерзім сияқты белгілі тақырып болса, соның дайын жауабын қосады. Мысал сұралса, дизайн суреттерін тіркеп жібереді.
- Хаттың өзі сізге Telegram-ға 📧 болып келеді.
- Бір адамға автожауап тәулігіне бір рет қана кетеді.

**Сіз жауап бересіз:** Telegram-дағы 🔥, ❓ немесе 📧 хабарға **reply** жасап жазсаңыз, жауабыңыз клиентке кетеді: Telegram-нан жазса Telegram-ға, поштадан жазса email-ге.

## 1. Не керек (толығырақ)

| Не | Қайдан алуға болады |
|---|---|
| **Telegram бот токені** | Telegram-да @BotFather → `/newbot` |
| **Gmail App Password** (қаласаңыз) | Google аккаунт → Қауіпсіздік → 2 қадамды растауды қосу → «App passwords». Gmail-де IMAP қосулы болуы керек |
| **Mail.ru App Password** (қаласаңыз) | Mail.ru → Настройки → Безопасность → «Пароли для внешних приложений» |

Python 3.10 немесе одан жаңа нұсқасы керек.

## 2. Қолмен орнату (start.bat / start.sh жұмыс істемесе)

```bash
cd bot
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python setup.py                  # токенді сұрап, .env жазады
```

Содан кейін іске қосыңыз:

```bash
python bot.py
```

## 3. Иесін тану

Бот бірінші іске қосылғанда экранға 6 таңбалы код шығарады. Сол кодты ботқа жазған адам иесі болып тіркеледі: оның ID-і `.env` ішіндегі `OWNER_CHAT_ID` жолына өзі жазылады.
Басқа аккаунтқа ауыстыру үшін `.env` файлындағы `OWNER_CHAT_ID=` жолын бос қалдырып, ботты қайта қосыңыз да, кодты жаңа аккаунттан жазыңыз.

## 4. Жауаптарды өзгерту: `answers.json`

Барлық жауап `answers.json` файлында тұр. Файлды кез келген мәтін редакторымен ашып, өзгертуге болады. Сақтаған соң, бот қайта қоспай-ақ жаңа нұсқаны қолданады.

- `topics`: тақырыптар. Әрқайсысында мыналар бар:
  - `keywords`: кілт сөздер. Сөздің басын жазу жеткілікті: `баға` сөзі «бағасы» мен «бағалар» сөздерін де табады;
  - `kk` / `ru`: қазақша және орысша жауап;
  - `button`: мәзірдегі батырма (міндетті емес).
- `handoff_keywords`: осы сөздер кездессе, хабар сізге беріледі («іс»).
- `handoff`, `unknown`, `greeting`, `email_autoreply`: жалпы жауаптар.

Жаңа тақырып қосу үшін `topics` ішіне тағы бір блок қосыңыз:
```json
{
  "id": "seo",
  "keywords": ["seo", "google", "гугл", "іздеу"],
  "kk": "SEO: 100К-дан бастап жеңіл SEO кіреді...",
  "ru": "SEO: начиная с 100К входит базовое SEO..."
}
```
> Файлды өзгерткенде тырнақшаларды және блоктар арасындағы үтірлерді өшіріп алмаңыз. Қате болса, бот логта соны жазады.

## 5. Дизайн каталогы

Суреттер `designs/` папкасында тұр. Басында newwave сайтының скриншоттары бар (компьютер мен телефон нұсқасы).

**Жаңа дизайн қосу:** ботқа фото немесе альбом жіберіп, астына былай жазыңыз:
```
#дизайн Кофехана сайты | жылы түстер, мәзір, галерея
```
- `/designs`: каталогтағы барлық дизайн
- `/deldesign id`: дизайнды өшіру

Каталогта 3-тен көп дизайн болса, бот клиентке таңдау батырмаларын көрсетеді.

> 🔥 хабарландыруға reply жасап фото жіберсеңіз, ол каталогқа емес, тікелей клиентке кетеді.

## 6. Командалар (тек сізге)

- `/help`: көмек
- `/list`: сіз жауап беріп жатқан клиенттер (әрқайсысының «🤖 Ботқа қайтару» батырмасы бар)
- `/designs`, `/deldesign id`: дизайн каталогы
- `/id`: chat ID

«🤖 Ботқа қайтару» батырмасын бассаңыз, бот сол клиенттің мәтіндеріне қайта жауап бере бастайды. Ал мәзір батырмалары әрқашан жұмыс істейді.

## 7. Пошта

- Әр 60 секунд сайын (`MAIL_POLL_SECONDS`) INBOX тексеріледі.
- Бірінші іске қосқанда ескі хаттарға жауап бермейді, тек осыдан кейін келген жаңа хаттарға жауап береді.
- Жарнама, рассылка және `noreply` хаттары өткізіліп жіберіледі.
- Хаттың «оқылмаған» белгісі өзгермейді.

## 8. Тәулік бойы жұмыс істету

Бот компьютер қосулы тұрғанда ғана жұмыс істейді. 24/7 жұмыс үшін арзан VPS серверге қойыңыз:

```ini
# /etc/systemd/system/newwave-bot.service
[Unit]
Description=newwave bot
After=network-online.target

[Service]
WorkingDirectory=/home/USER/newwaveculture/bot
ExecStart=/home/USER/newwaveculture/bot/.venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now newwave-bot
journalctl -u newwave-bot -f      # логтар
```

⚠️ `.env` файлын ешкімге жібермеңіз және GitHub-қа салмаңыз (`.gitignore`-да тұр).
